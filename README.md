# LeaveFlow – Employee Leave Management System

A responsive Employee Leave Management System built with React, TypeScript, Vite and Lucide React.

## Features
- Dashboard with leave balances and request statistics
- Apply Leave form
- Client-side validation
- Leave history table
- Search and status filtering
- Cancel pending requests
- LocalStorage persistence
- Toast notifications
- Responsive mobile/tablet/desktop UI

## Run

Requirements: Node.js 18+

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal, normally `http://localhost:5173`.

For production:

```bash
npm run build
```
